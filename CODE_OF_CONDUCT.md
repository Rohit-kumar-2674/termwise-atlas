# Community code of conduct

Welcome beginners, students, experienced developers, and people using limited hardware or a phone. Treat questions seriously. Give specific technical feedback without insults, harassment, discrimination, threats, or personal attacks. Respect privacy and consent; never post another person's credentials or personal information.

Contributions should make the guide more accurate, accessible, and useful. Avoid spam, deceptive cost claims, unauthorized-access instructions, and impersonating a tool vendor. Disagreement is welcome when it is supported by evidence and expressed respectfully.

Maintainers may edit or remove harmful content, close abusive discussions, or restrict participation after considering context. Report conduct concerns privately through an available maintainer contact; if no private channel is listed, request one without posting sensitive details publicly. Security vulnerabilities follow SECURITY.md.

This policy applies to project repositories, reviews, issues, and project-maintained community spaces. Everyone, including maintainers, is expected to follow it.
