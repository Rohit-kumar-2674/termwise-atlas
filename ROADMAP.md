# Roadmap

## Foundation delivered in 0.1.0

- [x] Canonical English learning path, consistent tool guides, honest cost/support labels
- [x] Windows, Linux, macOS, WSL, ChromeOS, Android/PRoot, and cloud/SSH guides
- [x] Ollama, OpenRouter, model/hardware references, current Google migration context
- [x] Git, API security, sandboxing, prompting, and structured troubleshooting
- [x] Read-only doctor, instruction-only setup wizard, eight learning labs
- [x] Searchable responsive docs, theme toggle, interactive chooser and compatibility filters
- [x] Automated validation and contribution templates

## Next: broader evidence

- [ ] Collect reproducible runtime reports from real Android/Termux and PRoot devices
- [ ] Add hardware-measured local-model results with fixed prompts and context settings
- [ ] Expand officially sourced agent coverage as projects demonstrate useful maintenance
- [ ] Add scheduled stale-claim review and release notes as providers change

## Community growth

- [ ] Reviewed Hindi translation pilot, then Spanish, French, Portuguese, German, Japanese, Korean, and other teams
- [ ] Versioned compatibility snapshots and documented upgrade comparisons
- [ ] More accessible screenshots and short task-specific walkthroughs
- [ ] Community-owned compatibility evidence with clear review status

Unchecked items are future work, not claimed features. No paid API access or account automation is required to contribute.
