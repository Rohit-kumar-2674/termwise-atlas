# Evaluate another coding agent

> **COMMUNITY CONTRIBUTION PATH** · **Last verified:** 2026-09-22 (documentation review).<br>
> **Tool version:** Candidate-specific; no additional agent certified. Platform execution coverage is recorded in [Validation](../maintenance/validation.md).

## What is it?

An expansion policy for this directory, not an endorsement of every similarly named package. New agents enter through a sourced contribution.

## Best For

Advanced users comparing a maintained project against their actual workflow.

## Cost

Classify client license, model price, hosting price, and optional services separately.

## Requirements

An official repository, license, installation page, supported architectures, documented provider mechanism, and a reproducible small test.

## Supported Platforms

Require evidence per operating system. “Runs on Linux” does not establish Termux support.

## Installation

Follow the candidate project's official release/install source only after checking its publisher and recent activity. This page intentionally has no invented universal install command.

## Configuration

Verify the API protocol, secret storage, telemetry, default permissions, and whether a local model still triggers cloud calls.

## First Command

Use its documented help/version command before opening a repository with secrets.

## Example Workflow

Try the same [bug-fix lab](../examples/fix-a-bug.md), compare the diff and tests, then report OS, architecture, version, model and failures. Do not publish credentials or claim “best” from one trial.

## Troubleshooting

If documentation is missing or installation requires bypassing access controls, stop the evaluation. Open a sourced request using the tool issue template.
