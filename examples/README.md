# Runnable learning fixtures

No provider is called by these examples. The HTML page and Python exercises need no third-party dependencies. The React example needs Node and an initial package install.

- `website/`: accessible static learning log.
- `python-lab/`: deliberately buggy fixture, independent checks, reviewed solution, and tested pure functions.
- `react-checklist/`: small React learning checklist with a production build and logic tests.

The intentionally failing cart module is labelled and is not the default test target. Copy it into ignored `practice/` before editing. The [eight tutorials](../docs/examples/index.md) explain prompts, acceptance criteria, commands, and review steps.
